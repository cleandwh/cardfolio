# 개인 재무 대시보드 — 설계서

카드폴리오와 같은 원칙: **서버·API·과금 없음**, 브라우저에서만 동작, 데이터는 내 기기에만 저장.

- 실행 주소(예정): https://cleandwh.github.io/cardfolio/finance/
- 코드: `finance/index.html` 한 파일 (CSS·JS 포함)
- 기능 3개: ① 가계부(뱅크샐러드 엑셀 일괄 업로드·자동 분류) ② 구독·고정지출 관리 ③ 대출·적금 계산기

---

## 1. 제약과 원칙

| 항목 | 결정 |
|---|---|
| 서버/API | 없음. 외부로 데이터 전송 금지 (fetch/XHR로 개인 데이터 전송 코드 작성 금지) |
| 외부 라이브러리 | SheetJS만 사용: `https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js`. 차트는 라이브러리 없이 인라인 SVG |
| 저장 | `localStorage` 키 `finance.v1` 하나에 JSON. 모든 읽기/쓰기 try/catch |
| 백업 | JSON 내보내기/가져오기 필수 (브라우저 데이터 삭제 대비) |
| 화면 | 모바일 우선(폭 360px 기준), 다크모드 대응, 한국어 |
| 금액 | 원 단위 정수로 저장·계산. 표시는 `toLocaleString('ko-KR')` |
| 개인정보 | 실제 엑셀/백업 파일은 절대 커밋하지 않음 (`.gitignore`에 `*.xlsx`, `*.xls`, `*.csv`, `finance-backup*.json`) |

## 2. 데이터 모델

```js
// localStorage['finance.v1']
{
  schema: 1,
  transactions: [Txn],
  subscriptions: [Sub],
  rules: [Rule],          // 사용자 분류 규칙 (뱅샐 분류보다 우선)
  settings: {
    excludeTransfers: true,   // '이체' 타입은 지출 통계에서 제외
    monthStartDay: 1,         // 월 기준일 (월급일 기준으로 보고 싶을 때)
    budget: { [category]: number }  // 선택: 카테고리별 월 예산
  },
  importLog: [{ at, fileName, added, skipped }]
}

Txn = {
  id,            // 중복 판정용 해시 (아래 3.3)
  date,          // 'YYYY-MM-DD'
  time,          // 'HH:mm' 또는 ''
  type,          // 'expense' | 'income' | 'transfer'
  amount,        // 양수 정수 (부호는 type으로 판단)
  category,      // 대분류
  subcategory,   // 소분류
  merchant,      // 내용(가맹점)
  method,        // 결제수단 (카드/계좌명)
  memo,
  source         // 'banksalad' | 'manual' | 'csv'
}

Sub = {
  id, name, amount, cycle,   // cycle: 'monthly' | 'yearly' | 'weekly'
  billingDay,                // monthly: 1~31, yearly: 'MM-DD'
  category, method, startDate, active, memo,
  matchKeyword               // 거래내역에서 이 구독 결제를 찾을 키워드
}

Rule = { id, keyword, field: 'merchant'|'memo', category, subcategory }
```

## 3. 가계부 — 뱅크샐러드 엑셀 업로드

### 3.1 파일 형식 (실제 파일로 검증 필요)
뱅크샐러드 '내보내기' 엑셀은 보통 여러 시트로 구성되고, 거래 시트의 열은 대략:
`날짜 | 시간 | 타입 | 대분류 | 소분류 | 내용 | 금액 | 화폐 | 결제수단 | 메모`

형식이 바뀔 수 있으므로 **열 위치를 고정하지 말고 헤더 이름으로 찾는다.**

### 3.2 파싱 절차
1. SheetJS로 읽기 (`XLSX.read(arrayBuffer, {type:'array', cellDates:true})`).
2. 모든 시트를 돌며 처음 20행 안에서 `날짜`와 `금액`을 동시에 포함하는 행을 헤더로 판정 → 그 시트를 거래 시트로 사용.
3. 헤더 별칭 매핑 (공백 제거 후 비교):
   - date: 날짜, 거래일, 거래일자, 일자
   - time: 시간, 거래시간
   - type: 타입, 구분, 유형
   - category: 대분류, 카테고리, 분류
   - subcategory: 소분류
   - merchant: 내용, 가맹점, 사용처, 적요
   - amount: 금액, 거래금액, 이용금액
   - method: 결제수단, 수단, 카드, 계좌
   - memo: 메모, 비고
4. 값 정규화:
   - 날짜: Date 객체 / 엑셀 일련번호 / `2026.10.01`·`2026-10-01`·`20261001` 모두 → `YYYY-MM-DD`
   - 금액: 쉼표·`원` 제거, 숫자화. 음수면 지출로 보고 절댓값 저장
   - 타입: `지출`→expense, `수입`→income, `이체`→transfer. 타입 열이 없으면 금액 부호로 판단
5. 헤더를 못 찾으면 **열 매핑 화면**을 띄워 사용자가 직접 지정 (일반 카드사 CSV도 이 경로로 처리).

### 3.3 중복 방지
`id = hash(date + time + amount + merchant + method)` (간단한 FNV-1a 32비트 → base36).
같은 기간을 다시 올려도 이미 있는 id는 건너뛴다. 같은 시각·같은 금액·같은 가맹점 거래가 실제로 2건인 경우를 위해, 파일 안에서 같은 키가 n번째로 나오면 키에 `#n`을 붙인다.

### 3.4 미리보기 → 확정
업로드 즉시 저장하지 않는다. "새 거래 N건 / 중복 M건 / 기간 A~B / 지출 합계" 미리보기 → [가져오기] 클릭 시 저장 → `importLog` 기록.

### 3.5 분류
우선순위: **사용자 규칙 > 뱅샐 대분류 > '미분류'**.
- 내역 화면에서 거래의 카테고리를 바꾸면 "같은 가맹점 전체에 적용 + 규칙으로 저장?" 묻기.
- 미분류 거래만 모아보는 필터 제공.

## 4. 구독·고정지출

- 수동 등록/수정/삭제, 활성·해지 토글.
- **자동 감지 제안**: 거래내역에서 가맹점명을 정규화(공백·괄호·숫자 꼬리 제거)해 묶고,
  - 최근 6개월 안에 3회 이상,
  - 간격 25~35일(월간) 또는 355~375일(연간),
  - 금액 편차 ±10% 이내
  
  면 "구독으로 등록할까요?" 카드로 제안. 무시한 제안은 다시 띄우지 않음(`settings.dismissedSubs`).
- 표시: 월 환산 합계(연간÷12, 주간×52÷12), 연 합계, 다음 결제일 순 정렬, 7일 이내 결제 강조.
- 결제일이 31일인데 그 달이 30일까지면 말일로 처리.

## 5. 계산기 (저장 불필요, 입력값만 localStorage에 기억)

### 5.1 대출 상환
입력: 원금 P, 연이율 %, 기간(개월) n, 상환방식, (선택) 거치기간.
- 월이율 r = 연이율/12/100
- 원리금균등: 월상환액 `A = P·r·(1+r)^n / ((1+r)^n − 1)` (r=0이면 P/n)
- 원금균등: 월 원금 P/n, 이자 = 잔액·r
- 만기일시: 매월 이자 P·r, 마지막 달 원금
- 출력: 월별 상환표(접기 가능), 총이자, 총상환액
- 원 단위 반올림, **마지막 회차에서 잔액 오차 보정**

### 5.2 중도상환 효과
현재 잔액·금리·남은 기간 + 중도상환액·수수료율 → "기간 단축" vs "월상환액 감소" 두 경우의 이자 절감액 − 수수료 비교.

### 5.3 예금 vs 적금
- 예금: 원금 × 연이율 × 기간 (단리) / 월복리 옵션
- 적금(정액 적립식, 단리): 이자 = 월납입 × 연이율/12 × n(n+1)/2
- 세금 옵션: 일반과세 15.4% / 세금우대 9.5% / 비과세 0%
- 출력: 세전이자, 세금, 세후 수령액, 실효 연수익률

### 5.4 목표 금액 달성 기간
목표액, 현재 보유액, 월 저축액, 예상 연수익률(월복리) → 달성 개월 수와 예상 날짜.

모든 계산기 하단에 "참고용 계산이며 실제 금융사 조건과 다를 수 있음" 문구.

## 6. 화면 구성 (하단 탭 5개)

1. **홈**: 이번 달 지출 합계, 전월 대비 증감, 카테고리 상위 5개(가로 막대 SVG), 다가오는 구독 결제 3건, 미분류 거래 수 배지
2. **내역**: 월 선택, 검색(가맹점/메모), 필터(타입·카테고리·결제수단·미분류), 거래 수정/삭제, 수동 추가
3. **구독**: 목록, 합계, 자동 감지 제안
4. **계산기**: 5.1~5.4 하위 탭
5. **설정**: 엑셀 업로드, 열 매핑, 분류 규칙 관리, 월 기준일, 이체 제외, 백업 내보내기/가져오기, 전체 삭제(2단계 확인), 업로드 기록

## 7. 개발 단계와 완료 기준

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| M1 | 뼈대 + 저장 + 백업 + 구독 관리 | 구독 등록 후 새로고침해도 유지, 백업 JSON 내보내고 전체 삭제 후 가져오면 복원 |
| M2 | 계산기 4종 | 원리금균등 1억·연 4%·360개월 → 월 477,415원 (±1원); 적금 월 50만·연 4%·12개월 단리 세전이자 130,000원 |
| M3 | 뱅샐 엑셀 업로드·중복 방지·분류·내역 화면 | 샘플 엑셀 2회 업로드 시 두 번째는 전부 중복 처리; 헤더 열 순서를 바꿔도 정상 파싱 |
| M4 | 홈 대시보드 + 구독 자동 감지 + 규칙 | 3개월치 샘플에서 월 구독 결제가 제안으로 뜸 |

테스트용으로 **가짜 데이터** 샘플 생성기를 설정 화면에 숨김 버튼으로 둔다(실제 개인 파일 커밋 금지 원칙 유지).

## 8. 남은 확인 사항
- 실제 뱅크샐러드 내보내기 파일의 시트명·열 이름 (헤더 행만 캡처해서 공유하면 충분)
- 월 기준일을 1일로 둘지 월급일로 둘지
