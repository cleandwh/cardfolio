## 1. S25 사진·영상 자동 백업 ⭐ 최우선

### 동작
1. S25에서 촬영 → **집 Wi-Fi + 충전 중일 때** 자동으로 노트20 SD에 복사 (Syncthing, 무료·외부 서버 없음)
2. 허브 사진 타임라인에 기존 SD 사진과 **합쳐서** 표시 (같은 사진 중복 제거)
3. 허브의 **"S25에서 지워도 되는 사진"** 화면: 노트20에 복사 완료·검증된 항목만, 오래된 순/용량 큰 순(영상 우선)
4. 사용자가 S25 갤러리에서 직접 삭제 → **노트20 사본은 그대로 유지**

### 반드시 지킬 안전장치
| 위험 | 대책 |
|---|---|
| S25에서 지우면 노트20에서도 지워짐 (동기화 기본 동작) | 노트20 폴더를 **받기 전용 + 삭제 무시(ignoreDelete)** 로 설정. H0에서 실제 삭제 테스트로 확인 |
| 노트20 SD가 사진의 유일한 원본이 됨 | 월 1회 PC·외장하드 복사 알림. "지워도 되는 사진" 목록은 **마지막 외부 백업 이후 것은 경고 표시** |
| Termux 앱 폴더에 저장 시 Termux 삭제하면 사진도 삭제됨 | H0에서 SD 저장 위치 확인. 앱 전용 폴더밖에 안 되면 **"Termux 삭제 금지"** 를 설정 화면 최상단에 고정 표시 |
| 모바일 데이터 소모 | 백업은 Wi-Fi에서만 |
| S25의 HEIC 사진·HEVC 영상 | 썸네일은 허브가 JPEG/WebP로 변환. 변환 지원 여부 H0에서 확인 |

### 백업 대상 (확정)
| S25 폴더 | 용도 |
|---|---|
| `DCIM/Camera` | 사진·영상 → 사진 타임라인 |
| `Pictures/Screenshots` | 스크린샷 → 사진 타임라인 (스크린샷 필터로 구분) |
| `Recordings` (음성 녹음) | 녹음 → 밤에 받아쓰기 → 메모 (P6) |

모두 같은 안전장치(받기 전용 + 삭제 무시, Wi-Fi에서만) 적용. 실제 폴더 경로는 H0에서 S25 내 파일 앱으로 확인.


## 2. 전체 기능과 단계

| 단계 | 내용 | 담당 | 의존 |
|---|---|---|---|
| **P0** | H0 세팅·측정 + Syncthing 백업 시험 + (선택) 출구 노드 | 사용자 | — |
| **P1** | 허브 서버 뼈대(PIN 로그인, 화면 제공) + **사진 색인·썸네일·타임라인 + 백업 폴더 합치기 + "지워도 되는 사진"** | Claude | — (테스트 사진으로 개발) |
| **P2** | 재무·기록 저장 위치 허브로 전환 + 데이터 이전 + **ntfy 푸시 알림 기반** | Claude | P1 |
| **P3** | 알림 규칙: 아침 브리핑 · 구독 결제 · 경조사 · 보증 만료 · **실비 청구 누락** · **카드 실적 부족**(카드폴리오 규칙 재사용) | Claude | P2 |
| **P4** | **홈 디스플레이 모드**(노트20을 거치대에: 시계·브리핑·"N년 전 오늘" 사진 액자) | Claude | P1 |
| **P5** | 질문·답변 ①②③ + **붙여넣기 자동 입력**(청첩장·주문 문자 → 기록) | Claude | P2, H0 측정값 |
| **P6** | 음성 메모 받아쓰기 · 자동 시작 · 새벽 백업 · 과열 보호 · 노트20 실설치 | Claude + 사용자 | P0~P5 |
| 나중 | 연말 결산, 여행 일지, 집·차 달력, 문서 보관함(OCR), 재구매 예측, 중고 판매 도우미, 카드 이벤트 수집, 광고 차단 DNS | — | 구조만 열어둠 |

**P1~P5는 노트20 없이 개발 환경에서 먼저 만들 수 있다** → H0를 기다리지 않고 바로 시작. 노트20 실측값(LLM 속도, SD 경로, HEIC 지원)은 설정값으로 빼 두고 H0 결과로 채운다.
